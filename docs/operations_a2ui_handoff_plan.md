# 采购销售日报 A2UI 改造与跨项目交接计划

## 交付与验证
1. 复用已验证的应用机器人原生 A2UI 通道及付款卡片视觉语言；指标直接来自既有快照，按群配置限制销售/采购范围，金额保留原有对账口径。验证无跨公司、无越权销售/采购数据。
2. 日报同时推送卡片、PDF 和 Excel；分阶段持久化回执，附件失败重试不得重复创建已成功的卡片。用失败恢复与重复投递测试验证。
3. 生成脱敏、可离线运行示例的交接包：架构、接入步骤、数据契约、源代码、模板、测试、部署/排错和版本清单。验证包内无凭据、无业务数据，离线示例可运行。
4. 定向回归、真实快照只读渲染和可视化预览；本次不额外发送业务群消息、不擅自部署生产新功能。

## 设计
- 同一公司经营日报合并展示被选中的销售与采购模块；仅选销售或采购时，卡片和附件均不包含另一模块。
- 首屏：公司、日期、同步状态、当日销售/采购金额；下方为日报笔数、覆盖率、月度对账差额，以及既有按日趋势图。无真实基期时不虚构环比。
- 同步缺失、无记录与负金额明确展示；人民币元用于指标，万元用于图表；不将销售减采购标为利润。
- 使用与付款卡片相同的公开组件目录、卡片分组、蓝色主色及真实 Chart 组件，不使用截图代替原生卡片。

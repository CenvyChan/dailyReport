## 🚀 快速配置流程

### 步骤1: 登录钉钉开放平台

1. 访问 https://open-dev.dingtalk.com
2. 登录企业管理员账号
3. 选择应用"飞诺斯日报推送"

### 步骤2: 创建互动卡片模板

#### 2.1 进入卡片搭建器

- 导航到：应用管理 → 消息 → 互动卡片
- 点击"创建卡片"
- 选择"高级版"（支持丰富布局和组件）

#### 2.2 搭建卡片布局

**顶部标题区**
```
容器（垂直布局）
├─ 文本: {{title}} (标题样式，居中)
└─ 文本: {{period}} (副标题样式，居中，灰色)
```

**统计概览区（三列卡片）**
```
容器（水平布局，等宽三列）
├─ 统计卡片1
│  ├─ 数字: {{total_count}} (大号，加粗)
│  └─ 标签: "总申请" (小号，灰色)
├─ 统计卡片2
│  ├─ 数字: {{total_amount}} (大号，加粗，橙色)
│  └─ 标签: "总金额" (小号，灰色)
└─ 统计卡片3
   ├─ 数字: {{progress_percent}} (大号，加粗，蓝色)
   └─ 标签: "进行中" (小号，灰色)
```

**Top 5收款人区（循环列表）**
```
容器（垂直布局）
├─ 标题: "🏆 Top 5 收款人"
└─ 循环容器: {{top_payees}} (最多5项)
   └─ 列表项
      ├─ 文本: {{payee_name}} (加粗)
      ├─ 标签组
      │  ├─ {{count}}条
      │  └─ ¥{{amount}}
      └─ 最新申请: {{latest_date}} | ¥{{latest_amount}}
```

**底部按钮区**
```
容器（水平布局，居中）
├─ 按钮: "📊 查看详情" (次要按钮)
└─ 按钮: "📥 下载Excel" (主要按钮)
```

#### 2.3 配置模板变量

在"变量管理"中定义以下变量（JSON Schema）:

```json
{
  "type": "object",
  "properties": {
    "title": {"type": "string", "description": "标题（如：付款申请周报）"},
    "period": {"type": "string", "description": "周期（如：2026-10-19 至 2026-10-25）"},
    "total_count": {"type": "number", "description": "总申请数"},
    "total_amount": {"type": "string", "description": "总金额（格式化）"},
    "progress_percent": {"type": "string", "description": "进行中占比"},
    "completed_count": {"type": "number", "description": "已完成数"},
    "in_progress_count": {"type": "number", "description": "进行中数"},
    "top_payees": {
      "type": "array",
      "description": "Top 5 收款人",
      "items": {
        "type": "object",
        "properties": {
          "rank": {"type": "number"},
          "payee_name": {"type": "string"},
          "count": {"type": "number"},
          "amount": {"type": "string"},
          "latest_date": {"type": "string"},
          "latest_amount": {"type": "string"},
          "status": {"type": "string"}
        }
      }
    },
    "excel_url": {"type": "string", "description": "Excel下载链接"},
    "detail_url": {"type": "string", "description": "详情页链接"}
  }
}
```

#### 2.4 配置按钮交互

- "查看详情"按钮：跳转链接 → {{detail_url}}
- "下载Excel"按钮：跳转链接 → {{excel_url}}

#### 2.5 保存并发布模板

1. 点击"保存"
2. 点击"发布"
3. **复制模板ID**（格式类似：`67c1c5e6-xxxx-xxxx-xxxx-xxxxxxxxxxxx`）

### 步骤3: 配置模板ID到数据库

SSH登录生产服务器：

```bash
ssh mesdevserver
docker exec -it daily-report-web python manage.py shell
```

执行以下Python代码：

```python
from integrations.models import DingtalkApp

# 获取钉钉应用配置
app = DingtalkApp.objects.first()

# 配置卡片模板ID（替换为实际值）
app.card_template_id = '67c1c5e6-xxxx-xxxx-xxxx-xxxxxxxxxxxx'
app.save()

print(f"✓ 卡片模板ID已配置: {app.card_template_id}")
exit()
```

## 🔧 常见问题排查

### Q1: 找不到模板ID在哪里

A: 在卡片搭建平台 → 我的卡片 → 点击卡片名称 → 右上角"设置" → "基本信息" → 复制"模板ID"

### Q2: 卡片发送失败，提示"模板不存在"

A: 
- 确认模板已"发布"（不是草稿状态）
- 确认模板ID复制正确（包含完整的UUID）
- 确认模板属于当前应用

### Q3: 卡片显示空白或数据显示不正确

A:
- 检查模板变量名与代码中 `build_payment_card_data()` 返回的字段是否匹配
- 在卡片搭建器中使用"预览"功能，填入测试数据验证布局

### Q4: 想修改卡片样式

A:
- 进入卡片搭建器 → 选择对应模板 → 编辑
- 修改完成后重新"发布"
- **无需修改代码或重启服务**（模板ID不变）

### Q5: 如何查看已发送的卡片效果

A:
- 在钉钉群中查看最近发送的消息
- 或在开放平台"卡片管理" → "投放记录"查看历史

## 🎨 设计建议

1. **配色方案**
   - 主色：钉钉蓝 (#0089FF)
   - 金额：橙色 (#FF6A00)
   - 已完成：绿色 (#52C41A)
   - 进行中：蓝色 (#1890FF)
   - 已终止：灰色 (#BFBFBF)

2. **字体大小**
   - 标题：18px，加粗
   - 副标题：14px，灰色
   - 统计数字：24px，加粗
   - 统计标签：12px，灰色
   - 列表项：14px

3. **间距**
   - 区块间距：16px
   - 列表项间距：12px
   - 内边距：12px

## 📝 代码实现说明

卡片数据生成逻辑在 `integrations/services/payment_card.py`:

- `build_payment_card_data()`: 生成卡片数据
- `send_interactive_card()`: 发送卡片到钉钉群

命令行工具 `send_payment_report` 会自动判断：
- 如果配置了 `card_template_id` → 使用卡片
- 如果未配置或发送失败 → 降级为文本消息
- 参数 `--no-card` → 强制使用文本消息

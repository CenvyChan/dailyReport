## Admin 配置方法

进入 /admin/integrations/erpanalysisschedule/ → 增加：

1. 公司选 FNS；要为其他公司推送应分别添加配置。
2. 勾选「启用月度分析」。
3. 每月运行日 1–28、运行小时 0–23，例如每月 1 日 8 时，时区为 Asia/Shanghai。
4. 勾选分析种类（至少一项）。
5. 通知群选择已启用且授权给所选公司的群。群配置的「推送公司」须包括 FNS；钉钉应用本身或应用公司映射也须允许 FNS，并已配置机器人 Code。
6. 保存。每月生成截至上个月末的近 12 个月分析；相同公司、分析月份仅自动生成/通知一次。通知群留空只生成报告、不推送。

工作服务：daily-report-erp-analysis，运行 python manage.py run_erp_analysis --watch，不阻塞原有日报同步/推送调度。

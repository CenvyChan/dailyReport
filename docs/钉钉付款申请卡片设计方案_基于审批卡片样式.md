# 钉钉付款申请周报卡片设计方案（基于审批卡片样式）

## 📐 设计目标

参考钉钉官方审批卡片样式（https://wolai.dingtalk.com/ddKAki4UNuBgu5o51Dv9XW），
设计付款申请周报互动卡片，使其具备：
- 清晰的信息层级
- 审批流程状态展示
- 可点击查看详情
- 支持Excel附件下载

## 🛠️ 技术实现要点

### 1. 审批卡片核心组件

参考官方审批卡片示例，需要使用：

- **标题栏**：应用图标 + 标题 + 时间
- **表单展示**：字段名-字段值的表单布局
- **状态标签**：不同颜色标识状态（进行中/已完成/已终止）
- **操作按钮**：主按钮（下载）+ 次按钮（查看详情）

### 2. 数据结构调整

根据审批卡片的数据格式，需要调整 `payment_card.py` 的数据结构：

```python
def build_payment_card_data(summary_data, period_info, report_type):
    """生成符合审批卡片样式的数据"""
    
    # 状态统计（使用审批卡片的状态字段）
    status_list = [
        {
            "status": "completed",
            "status_text": "已完成",
            "status_icon": "✅",
            "count": summary_data['status_summary']['completed'],
            "amount": format_amount(summary_data['status_summary']['completed_amount'])
        },
        {
            "status": "in_progress",
            "status_text": "进行中",
            "status_icon": "🔄",
            "count": summary_data['status_summary']['in_progress'],
            "amount": format_amount(summary_data['status_summary']['in_progress_amount'])
        },
        {
            "status": "terminated",
            "status_text": "已终止",
            "status_icon": "❌",
            "count": summary_data['status_summary']['terminated'],
            "amount": format_amount(summary_data['status_summary']['terminated_amount'])
        }
    ]
    
    # Top 5 收款人（审批卡片的列表项格式）
    top_payees = []
    for idx, payee in enumerate(summary_data['payees'][:5], 1):
        latest_app = payee['applications'][0] if payee['applications'] else None
        
        top_payees.append({
            "rank": idx,
            "rank_emoji": ["1️⃣", "2️⃣", "3️⃣", "4️⃣", "5️⃣"][idx-1],
            "payee_name": payee['payee'],
            "count": payee['count'],
            "amount": format_amount(payee['total_amount']),
            "latest_date": latest_app['create_time'].strftime('%m-%d') if latest_app else '',
            "latest_amount": format_amount(latest_app['amount']) if latest_app else '',
            "status_icon": STATUS_ICONS.get(latest_app['status'], '❓') if latest_app else '',
            "status_text": latest_app['status'] if latest_app else ''
        })
    
    return {
        # 卡片头部
        "card_title": f"💰 付款申请{'周报' if report_type == 'week' else '月报'}",
        "period": f"{period_info['label']} ({period_info['start_date'].strftime('%m-%d')} 至 {period_info['end_date'].strftime('%m-%d')})",
        
        # 统计概览
        "total_count": summary_data['total_count'],
        "total_amount": format_amount(summary_data['total_amount']),
        "progress_percent": f"{int(summary_data['status_summary']['in_progress'] / summary_data['total_count'] * 100)}%",
        "progress_detail": f"({summary_data['status_summary']['in_progress']}/{summary_data['total_count']})",
        
        # 状态列表
        "status_list": status_list,
        
        # Top 5 收款人
        "top_payees": top_payees,
        "remaining_count": max(0, len(summary_data['payees']) - 5),
        
        # 按钮链接
        "excel_download_url": "dingtalk://",  # 实际应该是文件下载链接
        "detail_page_url": "https://your-domain.com/payment-report/detail"  # 可选的详情页
    }
```

#### 步骤3：配置样式

**颜色规范**：
- 主色：#0089FF（钉钉蓝）
- 成功色：#52C41A（绿色）
- 进行中：#1890FF（蓝色）
- 错误色：#FF4D4F（红色）
- 金额：#FF6A00（橙色）

**字体大小**：
- 卡片标题：16px，加粗
- 周期：12px，灰色 #8C8C8C
- 统计数字：20px，加粗
- 统计标签：12px，灰色
- 收款人名称：14px，加粗
- 金额：14px，橙色
- 最新记录：12px，灰色

**间距**：
- 区块间距：16px
- 卡片内边距：12px
- 列表项间距：8px

#### 步骤4：配置按钮交互

2. **下载Excel**按钮

### 4. 卡片发送API调整

更新 `send_interactive_card()` 函数：

```python
def send_interactive_card(client, group_id, card_data, template_id):
    """发送互动卡片到钉钉群"""
    
    # 钉钉互动卡片API
    payload = {
        "cardTemplateId": template_id,
        "outTrackId": f"payment_report_{datetime.now().strftime('%Y%m%d%H%M%S')}",
        "conversationId": group_id,
        "conversationType": "2",  # 2=群聊
        "cardData": {
            "cardParamMap": card_data
        },
        "callbackType": "STREAM",  # 或 HTTP
    }
    
    # 发送卡片
    result = client.post('/v1.0/card/instances/createAndDeliver', payload)
    return result
```

## 📊 优势分析

### 相比纯文本消息的优势

1. **视觉层级清晰**：通过卡片、分割线、图标等元素，信息层级一目了然
2. **状态可视化**：使用颜色和图标标识审批状态，比纯文本更直观
3. **交互体验好**：按钮点击、链接跳转，比复制链接体验更好
4. **品牌一致性**：与钉钉审批的视觉风格统一，用户认知成本低
5. **移动端适配**：钉钉卡片自动适配手机和PC，响应式布局

### 实施建议

1. **第一阶段**：实现方案一（审批摘要卡片），满足基本展示需求
2. **第二阶段**：如果需要更多交互（评论、提醒），升级为方案二
3. **第三阶段**：如果数据量大需要复杂表格，开发H5详情页（方案三）

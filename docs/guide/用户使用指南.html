用户使用指南

面向销售、采购与管理人员　·　访问地址 http://172.16.77.80:8001/　·　更新于 2026-10-30

先理解一件事：数据按公司隔离 系统里有飞诺斯电子科技有限公司和宁波汇慧有限公司两家公司。你的账号和密码两家共用， 但业务数据完全分开——登录飞诺斯时看到的客户、日报、报表，都只属于飞诺斯。 所以每次操作前，先确认导航栏上的「当前公司」是不是你要的那家。

SECTION 03

3. 切换公司

登录后，导航栏右侧显示当前公司。点开这个胶囊就能切换；只授权一家公司时，面板里会提示「你的账号只授权了这一家公司」，不需要切换。

  1. 点右上角「当前公司：××」胶囊。
  2. 在「切换公司」下拉里选择另一家公司。
  3. 点「切换」。所有页面（日报、报表、导出、导入）都会跟着换到那家公司的数据。
怎么确认切换成功看「当前公司」标签变了没有。列表里的数据也会整体变化——两家公司的客户和金额本来就不一样。
不要用两个标签页分别看两家公司当前公司记录在同一个登录会话里，任一标签页切换都会影响其他已打开的页面。需要对比两家数据时，请分别导出 Excel。

  1. 点导航栏「销售」，进入销售日报列表。

提示「该客户还没有分配销售负责人」 管理员代录时如果选了未分配客户，会被拦住。请先在客户资料里把该客户分配给具体业务员，再录日报。

列表、筛选与合计

列表默认按日期倒序。日期栏支持今天／本周／本月／本年／全部和前后翻页；下面还可以按负责人、客户、币种筛选，或直接搜索客户与负责人。搜索会跨全部时间，不受日期框限制。

顶部的记录数、数量合计、美元金额、折算人民币合计始终跟着当前筛选口径走，翻页不会改变合计。

删除不可撤销点删除前请再确认一遍行内容。所有新增、修改、删除都会记入操作日志，可追溯。
SECTION 05

5. 维护客户、供应商与汇率

客户（销售角色）

「资料 → 客户」里只会列出你自己负责的客户。新增客户时，系统默认把你本人设为负责人，保存后立即出现在你的录入候选里。

  • 客户名称在同一家公司内不能重复；两家公司可以各有一个同名客户。
  • 客户可以停用。停用后不再出现在录入候选里，但历史日报保留。
  • 管理员能看到本公司全部客户，并可在客户表单里调整负责业务员（可多选）。

供应商（采购角色）

入口是「资料 → 供应商」，逻辑与客户完全对称：只看自己负责的供应商，新增时自动把自己设为采购负责人。

汇率（管理员）

「资料 → 汇率」按公司 + 月份维护美元兑人民币汇率，每月一条。外销销售和国外采购在保存时自动取业务日期所在月份的汇率作为快照；已经保存的日报不会因为以后改汇率而变化。

先维护汇率，再录外币业务缺当月汇率时，外币日报保存会直接报错。内销/国内采购不受影响。

采销对比

「分析 → 采销对比」按月展示全公司口径的采购入库金额与销售金额：上方是每日销售 vs 采购柱状图，下方是逐日明细表，最后一行是月度合计。金额均为未税口径，与日报录入金额一致。

  • 「每天占比」= 当日采购 ÷ 当日销售，超过 100% 说明当天进货多于出货，属正常波动，不代表利润率。
  • 可按年月切换，也可以导出当月对比 Excel。
  • 只要账号能进入销售或采购任一模块，就能查看本公司的对比表；报表查看者也可以。
SECTION 07

7. 金蝶数据：核对、出入库与客商映射

系统会和金蝶云星空定时同步出入库单据。这里的页面都是只读的，数据由后台同步任务写入。

系统数据 ↔ 金蝶核对

按月、按业务类型（销售出库 / 采购入库）对比两侧的每日笔数、数量与金额：

列含义
系统笔数 / 数量 / 金额本系统日报录入或历史导入的记录，金额为未税折人民币
金蝶单据 / 数量 / 金额金蝶库存发生单据，金额口径可能含税
金额差 / 数量差金蝶 − 系统。用于发现漏录、多录或口径差异，需要人工判断
差值是线索，不是错误提示两侧口径本来就不同（系统是业务员提报，金蝶是财务库存单据），有差额是正常的。重点看差额异常放大的日期，结合「金蝶出入库」明细排查。

金蝶出入库

列出已同步的金蝶单据，可按单号、客商、内码搜索。点进去能看到单据头信息和逐行物料明细（物料、规格、数量、单位、单价、金额）。被金蝶删除或反审核的单据会自动置为无效，不再计入核对。

金蝶客商映射

金蝶里的客户/供应商名称往往和本系统的简称不一致，需要把两侧对应起来。系统会先做模糊匹配并给出候选，但必须人工逐条确认：

  1. 在「分析 → 客商映射」按状态筛选，优先处理「待人工审核」。
  2. 核对金蝶名称与候选列表，选择正确的系统客户/供应商。
  3. 保存后状态变为「人工确定」，后续核对和日报就能对上号。
  • 一个系统客商可以挂接多个金蝶编码；规则是同名或曾用名都能归到一处。
  • 业务员只能挂接自己负责的客商，看不到别人的映射；清除挂接只有管理员可以操作。

「分析 → 钉钉付款」汇总从钉钉审批同步过来的付款申请，用于随时查看申请金额与审批进度。

状态 / 结果审批中、已完成、已终止
金额审批单中的付款金额

  • 管理员在页面右上角可以手动「同步当月数据」「更新未完结」，日常无需操作，后台会定时同步。
  • 本页面不能审批，审批请回到钉钉完成；系统只做汇总和报表。

付款申请周报 / 月报

除经营日报外，管理员还可以配置把钉钉付款申请按日、周、月汇总推送到指定钉钉群。周报在每周一发送，月报在每月 1 日发送，内容包含：

  • 总计笔数与金额、已完成/进行中数量；
  • 按收款人汇总的金额与明细；
  • Excel 附件（汇总统计、按收款人汇总、明细等 4 个工作表）。
没收到推送？先检查垃圾邮件箱和钉钉群是否被折叠；再确认当天是否真的有数据、金蝶同步是否覆盖到该日期；仍有问题联系管理员查看「发送记录」——里面记录了每次发送的成败与失败原因，并支持补发。
SECTION 10

10. 导入历史数据

批量导入由管理员操作。共 5 个入口，流程一致：下载模板 → 按模板填写 → 上传预览 → 正式导入。

导入什么菜单入口模板里的列
客户资料 → 客户 → 导入客户客户名称（也兼容「名称」）
供应商资料 → 供应商 → 导入供应商供应商名称（也兼容「供应商」「名称」）
用户系统 → 用户 → 导入用户用户名、姓名、角色、初始密码

SECTION 11

11. 常见问题

登录时下拉框里没有我要的公司？
管理员还没给你授权这家公司。账号是两家共用的，但需要逐家开授权。
登录后提示「当前账号没有可进入的公司」？
你的账号一家公司都没授权。找管理员在「用户公司授权」里添加。
导航栏没有「切换公司」？
说明你只被授权了一家公司，不需要切换，属正常。
客户下拉框里找不到某个客户？
三种可能：① 客户还没在这家公司建档（另一家有不算）；② 客户没分配给你；③ 客户被停用了。都需要管理员处理。
为什么我能看到同事的日报，却点不了「编辑」？
日报在本公司内全员可见，便于核对；但写权限只属于该客户的负责业务员（采购看供应商负责人）和管理员。需要代录或修改时，请找对应的负责人。
保存时提示缺少汇率？
外销/国外采购需要业务日期所在月份的汇率，而汇率按公司分别维护。请管理员在「汇率」里补录这家公司这个月的汇率。
上传 Excel 后提示姓名没有匹配到账号？
「业务跟单/采购员」必须对应系统已有账号，系统不会自动建号。请先建账号，或把源表姓名改成系统里的姓名/用户名；如果提示重名歧义，说明有两个同名账号，需要管理员先区分。
上传 Excel 提示格式或数值无效？
先下载模板对照列名。常见原因：日期格式不对、数量填了小数或 0、金额是文本（单元格左上角有绿色小三角）、销售类型写了「内销售」之类不认的词。
忘记密码怎么办？
找管理员重置。重置后会给你一个新的初始密码，下次登录会要求你再改一次。
能同时开两个浏览器窗口，一个看飞诺斯一个看宁波汇慧吗？
不行。当前公司记录在同一个登录会话里，切换会影响所有已打开的页面。需要对比两家数据时，请分别导出 Excel。
没收到每日推送怎么办？
先看垃圾邮件箱和钉钉群消息是否被折叠；再确认当天是否有数据、金蝶同步是否正常；仍没有就联系管理员查「发送记录」，里面能看到每次发送的成败和失败原因。
在哪里打开这份指南？
登录按钮右侧的 ?、系统内主题开关旁的 ?，或头像菜单里的「帮助」，都会新开标签页打开。

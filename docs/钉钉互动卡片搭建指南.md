## 1. 创建卡片模板

### 1.1 进入钉钉开放平台

1. 访问 [钉钉开放平台](https://open-dev.dingtalk.com)
2. 登录后选择你的应用：**飞诺斯日报推送**
3. 进入 **应用开发 → 互动卡片**
4. 点击 **创建卡片模板**

### 1.2 基础信息

- **模板名称**: 付款申请周报卡片
- **模板说明**: 展示周期内付款申请统计、Top 5收款人及状态分布
- **适用场景**: 群聊
- **模板类型**: 普通卡片

## 2. 卡片布局设计

### 2.1 卡片头部 (Header)

| 配置项 | 值 |
|--------|-----|
| 标题 | `{{title}}` |
| 副标题 | `{{dateRange}}` |
| 图标 | 💰 (选择钱包图标) |
| 主题色 | 蓝色 (#1890FF) |

### 2.2 卡片主体 (Body)

#### 布局 1: 统计概览 - 三栏布局

```
┌──────────────────────────────────────┐
│ 📋              💰           🔄      │
│ **{{stats[0].value}}**  **{{stats[1].value}}**  **{{stats[2].value}}** │
│ {{stats[0].label}}  {{stats[1].label}}  {{stats[2].label}} │
└──────────────────────────────────────┘
```

**组件类型**: `column_set`（三列均分）

**每列内容**:
- 第1列: Icon + 大号数字 + 标签
  - Icon: `{{stats[0].icon}}`
  - 数字: `{{stats[0].value}} {{stats[0].unit}}`
  - 标签: `{{stats[0].label}}`

- 第2列: 同样结构，使用 `stats[1]`
- 第3列: 同样结构，使用 `stats[2]`

**样式**:
- 数字字体大小: 24px
- 数字字重: Bold
- 标签字体大小: 12px
- 标签颜色: #999999

#### 布局 2: 分隔线

**组件类型**: `divider`

#### 布局 3: Top 5 标题

**组件类型**: `text`
- 内容: `🏆 Top 5 收款人`
- 字体大小: 16px
- 字重: Bold

#### 布局 4: Top 5 列表 - 循环容器

**组件类型**: `list` (循环渲染)
**数据源**: `{{topRecipients}}`

**列表项模板** (单个收款人卡片):

```
┌─────────────────────────────────────┐
│ {{item.rank}}. {{item.name}}         │
│ {{item.count}}条 | {{item.amount}}   │
│ [最新] {{item.latest.date}}          │
│        {{item.latest.amount}}        │
│        {{item.latest.status_text}}   │
└─────────────────────────────────────┘
```

**列表项组件结构**:
1. **容器** (`container`)
   - 背景色: #F7F8FA
   - 内边距: 12px
   - 圆角: 8px
   - 外边距: 8px 0

2. **第一行** (`text`)
   - 内容: `{{item.rank}}. {{item.name}}`
   - 字体大小: 14px
   - 字重: Bold

3. **第二行** (`text`)
   - 内容: `{{item.count}}条 | {{item.amount}}`
   - 字体大小: 12px
   - 颜色: #666666

4. **第三行** (`text`, 条件显示)
   - 显示条件: `{{item.latest}}`存在时
   - 内容: `[最新] {{item.latest.date}} {{item.latest.amount}} {{item.latest.status_text}}`
   - 字体大小: 11px
   - 颜色: `{{item.latest.status_color}}`

#### 布局 5: 剩余收款人提示

**组件类型**: `text` (条件显示)
**显示条件**: `{{remainingRecipients}} > 0`
- 内容: `...还有 {{remainingRecipients}} 个收款人，详见Excel报表`
- 字体大小: 12px
- 颜色: #999999
- 样式: 斜体

### 2.3 卡片底部 (Footer)

**组件类型**: `note`
- 内容: `📎 详细数据已生成Excel报表，请查看附件`
- 样式: 信息提示样式

## 3. 配置模板变量

在卡片搭建器右侧"模板变量"面板中配置：

### 3.1 顶层变量

```json
{
  "title": {
    "type": "string",
    "description": "报表标题",
    "example": "付款申请周报"
  },
  "dateRange": {
    "type": "string",
    "description": "日期范围",
    "example": "2026-10-19 至 2026-10-25"
  },
  "hasData": {
    "type": "boolean",
    "description": "是否有数据",
    "example": true
  },
  "remainingRecipients": {
    "type": "number",
    "description": "剩余收款人数量",
    "example": 56
  }
}
```

### 3.2 数组变量: stats

```json
{
  "stats": {
    "type": "array",
    "description": "统计指标(固定3个)",
    "items": {
      "icon": "string (emoji)",
      "label": "string",
      "value": "string",
      "unit": "string"
    },
    "example": [
      {
        "icon": "📋",
        "label": "总申请",
        "value": "75",
        "unit": "条"
      },
      {
        "icon": "💰",
        "label": "总金额",
        "value": "¥1.5M",
        "unit": ""
      },
      {
        "icon": "🔄",
        "label": "进行中",
        "value": "76%",
        "unit": "(57条)"
      }
    ]
  }
}
```

### 3.3 数组变量: topRecipients

```json
{
  "topRecipients": {
    "type": "array",
    "description": "Top 5 收款人",
    "items": {
      "rank": "number",
      "name": "string",
      "count": "number",
      "amount": "string",
      "latest": {
        "date": "string",
        "amount": "string",
        "status_text": "string",
        "status_color": "string"
      }
    },
    "example": [
      {
        "rank": 1,
        "name": "上海宏开国际贸易有限公司",
        "count": 4,
        "amount": "¥166,892.75",
        "latest": {
          "date": "2026-10-22",
          "amount": "¥55,495.00",
          "status_text": "进行中",
          "status_color": "#1890FF"
        }
      }
    ]
  }
}
```

## 5. 可视化搭建步骤

### Step 1: 创建容器

1. 拖入 **列布局** 组件 (3列)
2. 每列设置宽度为 33.33%

### Step 2: 添加统计指标

在每列中：
1. 拖入 **文本** 组件显示 icon
2. 拖入 **文本** 组件显示数值（设置为加粗、大号）
3. 拖入 **文本** 组件显示标签（设置为小号、灰色）

### Step 3: 添加分隔线

拖入 **分隔线** 组件

### Step 4: 添加标题

拖入 **文本** 组件，内容为 "🏆 Top 5 收款人"

### Step 5: 添加循环列表

1. 拖入 **循环容器** 组件
2. 设置数据源为 `topRecipients`
3. 在循环容器内部搭建单个收款人卡片：
   - 添加容器（设置背景色、圆角）
   - 添加收款人名称文本
   - 添加统计信息文本
   - 添加最新申请文本（设置条件显示）

### Step 6: 添加备注

拖入 **备注** 组件，提示查看Excel附件

## 7. 常见问题

### Q: 卡片无法发送？

**A:** 检查以下几项：
1. 模板ID是否正确配置
2. 机器人是否有发送卡片权限
3. 数据格式是否匹配模板变量

### Q: 卡片显示异常？

**A:** 
1. 在搭建器中预览是否正常
2. 检查数据中是否包含特殊字符需要转义
3. 确认条件渲染的字段是否存在

### Q: 如何更新已发送的卡片？

**A:** 
```python
# 保存发送时返回的 outTrackId
result = send_interactive_card(...)
out_track_id = result['outTrackId']

# 更新卡片
client.put(f'/v1.0/card/instances', {
    'outTrackId': out_track_id,
    'cardData': updated_card_data,
})
```

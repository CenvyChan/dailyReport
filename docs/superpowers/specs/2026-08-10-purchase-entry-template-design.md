# 采购数据录入模板设计

## 目标

生成一份可直接录入采购入库明细、粘贴销售明细并自动生成月度采购/销售未税金额对比的 Excel 模板。模板沿用销售工作簿“一行一笔明细，报表按日期汇总”的工作方式，但不建立脆弱的外部工作簿链接。

## 已确认口径

- 采购金额和销售金额均按未税金额处理。
- 销售明细沿用源表的六个核心字段：客户名称、业务跟单、销售类型、出货日期、数量、金额。
- 采购明细一行代表一笔入库记录；金额列为入库金额（未税）。
- 月度占比定义为：月度采购入库总额 / 月度销售总额；不使用每日占比的简单平均。

## 工作簿结构

### 采购入库明细

录入区字段：供应商名称、采购员、采购类型、入库日期、入库数量、入库金额（未税）、备注。保留 5,000 行录入空间，冻结表头，日期和金额使用可计算的数值格式。

### 销售数据

粘贴区与销售源表保持相同六列结构，金额列标记为“销售金额（未税）”。此页只放原始记录，不改写原始金额，也不依赖源文件路径。

### 月度对比

- 顶部提供“统计月份”输入单元格，默认使用当前月份的月初日期。
- 下方生成当月 31 行日期，非当月日期显示为空。
- 入库金额按入库日期从 `采购入库明细` 汇总。
- 销售金额按出货日期从 `销售数据` 汇总。
- 占比在销售金额为 0 或日期为空时显示为空，避免 `#DIV/0!`。
- 月度合计占比使用合计入库金额 / 合计销售金额。

## 样式和可维护性

- 参考 FNS 表的宋体、浅色标题带和表头边框风格。
- 输入区域使用浅黄色，计算区域使用浅绿色或浅蓝色，颜色只用于区分可编辑与公式单元格。
- 明细区域使用筛选表和冻结表头；不对未使用的整列设置格式。
- 所有计算公式引用明确的有限范围，便于审计和后续扩展。
- 模板不预填业务数据，仅预填统计月份和公式。

## 验证标准

- 填入一笔采购和一笔销售后，月度对比能在对应日期显示金额。
- 销售金额为 0 时，占比为空而不是错误值。
- 月度合计等于明细金额合计，月度占比等于两项合计之比。
- 所有工作表渲染后标题、表头、金额和百分比均清晰可见，无截断或重叠。
